What is CSCSCA

CSCSCA, or Charles' Super Cool Sound Change Applier, is a sound change applier made to simulate the phonological evolution of languages over time.

It is simmilar to other sound change appliers like Lexurgy and SCA² with its own syntax (see help).

CSCSCA aims to be be simple and easy to use while providing as much functionaliy as needed. It also has many quality-of-life features including support for multi-character phones and diacritics, comments, and evolution tracing.


The source code for the core sound change applier can be found here.



Technical and Data Collection

This website collects no data. It does save the content of the rules editor to your brower's local storage so it can be loaded next time you open the page, but this information does not leave your device.


This website runs CSCSCA through a Web Assembly wrapper meaning that all execution stays on your device.
