Rules

A standard rule is written as follows:


The input and output of a rule are made up of phones. Phones are made up of characters not separated by whitespace like a, á, ts, and a_phone.

Each character in the input is considered to be a phone.

An input achȍ becomes the phones a, c, h, and ȍ.

Note: the diacritic, \u{030F}, remains attached to the o as any¹ unicode combining characters will be combined with the proceeding base character.


If, in the example above, ch is intended to represent tʃ, the phones may be merged with a rule like:

producing the phones a, tʃ, and ȍ.



(1) This may not be up to date with the latest unicode version, but should support the vast majority use cases.
